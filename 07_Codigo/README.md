# Código-fonte

Disponível: [gerador Python de documentação](Gerador_Documentacao/NEXUS_Gerador_Documentacao.py), que produz desenhos, tabelas e pacote de arquivos a partir de uma geometria comum.

Esse código **não é o firmware** do Arduino Mega ou ESP32. Os programas de controle ainda precisam ser incorporados com comentários, mapa de pinos confirmado, bibliotecas, versões e instruções de execução.

As regras que orientarão essa implementação estão na [especificação funcional](../04_Automacao/NEXUS_Especificacao_Automacoes_R01.txt). Nenhum teste de automação física está declarado como concluído.
