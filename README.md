# NexusSmartHome2050
Nexus - projeto executivo de Smart Home 2050 (BLUEPRINT/Engineering 2026.2 - UniFECAF). Integra arquitetura civil, elétrica com Smart Grid, hidráulica com reuso de água, automação IoT e segurança eletrônica em um sistema interoperável. Protótipo funcional com ESP32, sensores e dashboard em tempo real.
